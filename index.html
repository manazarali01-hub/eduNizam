Common Questions

            
Student add nahi ho raha?
Head account se Students → Add Student kholen. Sirf Student Name required hai; baqi profile details optional hain.

            
School details ya logo kahan change hon?
Head of Institute ke account mein Settings kholen aur Institute Settings se details save karein.

            
Data doosre device par chahiye?
Settings ke Cloud Backup & Sync section mein cloud connection/status check karein.

            
Complaint ya technical issue kaise bhejein?
Helpdesk & Complaints section mein ticket create karke issue track karein.
